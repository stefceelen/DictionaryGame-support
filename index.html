Common Questions

How do I start a game?

One player creates a game and shares the game code with friends. Everyone joins using that code. Players can also scan the game QR code from within the game app.

How many players can join?

Bookworm supports up to 12 players per game.

The game is stuck — what do I do?

Try leaving the game and rejoining using the same game code. If the issue persists, contact us.
